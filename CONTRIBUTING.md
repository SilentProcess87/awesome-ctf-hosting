# Contributing

Corrections and additions are welcome, including ones about CTF-Hub, which maintains this list.

- One entry per pull request, in the form `[Name](link) - Description.`
- Link the page that supports the claim (the project's own site, docs or repository).
- No prices: they go stale. Say how it is priced, not how much.
- If a project is archived or has gone quiet, say so and move it to "Archived or dormant".
- Do not post the Easter egg flag in issues or pull requests.
